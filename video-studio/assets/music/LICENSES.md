# Music library

Shared tracks for all video projects. The MP3s are **not committed** (the licence forbids redistributing them as standalone files). Run `npm run music` to download everything listed in `tracks.json`. Use one in a storyboard with `"music": "@library/<file>.mp3"`.
To add a track: add it to `tracks.json` and to the table below. Only add tracks whose licence allows commercial use on YouTube **without** Content ID registration
(Content ID-registered tracks get copyright claims on upload even when licensed).
